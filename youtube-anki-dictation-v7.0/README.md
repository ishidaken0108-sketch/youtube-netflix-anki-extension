# YouTube → Anki Dictation v7.0.0 — Clean Install

この版は過去版からの差分更新ではなく、いったん旧拡張を削除して新規インストールする前提のクリーン版です。旧設定・旧辞書・旧デバッグログを移行するコードは含みません。

## AI
- 字幕校閲: Gemini 3.5 Flash-Lite
- 日本語翻訳: Gemini 3.1 Flash-Lite
- Gemini APIキーは1つだけ使用
- AI処理はGemini APIだけを使用します
- GeminiへHOLO標準辞書・ユーザー辞書をヒントとして送りません
- 校閲・翻訳とも動画タイトル、チャンネル、説明欄、前後字幕を文脈として使用
- Geminiデバッグログで送信文脈・生レスポンス・固有名詞判定・辞書登録結果を確認可能（APIキーは記録しない）

## 字幕校閲
- ASR誤認識、固有名詞、誤重複、噛み、false startを校閲
- 意図的な反復や話者自身の文法・スラングは維持
- 前後字幕もASRであり、同じ誤認識の反復を正しさの証拠として扱わない

## ユーザー辞書
- 常に「YouTube元字幕 → 最終表記」を保存
- 途中のHOLO標準辞書適用結果をfromにしない
- 例: Flo Glee → FLOW GLOW → FLOWGLOW の場合、保存は Flo Glee → FLOWGLOW
- 語数が変わる固有名詞も前後の不変語をアンカーにして対応範囲を決定
- Gemini自動学習は高確信度の固有名詞修正だけ
- 誤重複・false start等は辞書登録しない

## 音声切り出し
- 手動で開始単語・終了単語を選んだ場合、字幕パネルに表示されたYouTube動画タイムコードを基準に音声を切り出す
- 保存ボタンを押した時刻からの相対時間では切らない
- 一時停止して数秒待ってから保存しても、選択した動画区間は変わらない
- Geminiが文章中の重複を削除しても音声区間には影響しない

## 新規インストール
1. 旧版をChromeから削除
2. このフォルダを新しく展開
3. chrome://extensions で「デベロッパーモード」をON
4. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを指定
5. 設定画面でGemini APIキーとAnki設定を入力
6. すでに開いているYouTubeタブは1回再読み込み
