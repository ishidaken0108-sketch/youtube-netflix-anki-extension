日本語訳・単語/熟語の保存先：Mnemonics（固定）

自動翻訳を有効にする場合、選択したノートタイプに Mnemonics フィールドが必要です。

Gemini API（Anki保存時のみ）

字幕校閲は gemini-3.5-flash-lite を使用します。選択字幕・前後字幕・動画URL・タイトル・チャンネル・説明欄を使って、ASR誤認識、固有名詞、誤重複、噛み・false startなどを校閲します。実際に話した文法やスラングは添削しません。

日本語訳・単語/熟語抽出は gemini-3.1-flash-lite を使用します。校閲後の確定英文をTARGETとして、動画タイトル・チャンネル・説明欄・前後字幕を文脈に使います。前後字幕は抽出対象にはしません。

ここは語彙の細かさ・難易度・分割方法を自由に調整する欄です。JSON形式やTARGET限定など、カード生成を壊さないための最低限の指令は拡張側で固定しています。初期値では、たとえば have to be selfish を1項目にまとめず、have to be と selfish に分けるなど、応用しやすい単位へ細分化します。

Gemini APIキーは1つだけで、校閲と翻訳の2モデルを使い分けます。 それぞれ別モデルへのAPIリクエストになるため、モデルごとのレート制限が適用されます。

辞書の候補はGeminiへ一切渡しません。 HOLO標準辞書やユーザー辞書をヒント・保護語として送らず、動画文脈だけで判断させます。

APIキーはこのPCのChromeローカルストレージに保存し、Chrome同期には保存しません。個人利用向けの構成です。拡張機能へAPIキーを直接埋め込んで配布しないでください。

校閲が失敗した場合は元字幕のまま保存します。日本語訳・語彙抽出が失敗した場合もカード作成は続行し、Mnemonicsだけ空欄になります。

直近30件のGemini処理ログ（校閲・翻訳）を保存します。APIキーは保存しません。 Geminiへ実際に送った動画タイトル・チャンネル・説明欄・前後字幕、Geminiの生JSON、固有名詞判定、辞書登録結果を確認できます。

字幕校閲辞書

字幕表示時は ユーザー辞書 → HOLO標準辞書 の既知修正だけを即時補正します。字幕を開いた時点ではGeminiによる抽出・校閲は行いません。

正しい表記 = 認識揺れ1, 認識揺れ2 の形式です。たとえば Riona = lyona や FLOW GLOW = flo glee のような安全な綴り揺れは直接補正します。一般英単語と衝突しやすい候補は自動置換しません。Geminiへ辞書候補を渡すこともありません。

ユーザー辞書

字幕パネルの「字幕修正」でユーザーが明示的に直した対応はここへ登録します。途中の表示結果ではなく、YouTubeの元字幕 → 最終表記を1対1で保存します。たとえば Flo Glee → FLOW GLOW → FLOWGLOW と直した場合は Flo Glee → FLOWGLOW、bi boo → Bijou のように語数が変わる場合も前後の一致語をアンカーにして元字幕の正しい範囲を保存します。また、Anki保存前のGemini校閲で高確信度の固有名詞を修正した場合だけ自動登録し、対応は必ず元のSOURCE TEXT → 最終校閲文から直接作ります。Geminiの途中候補や人工的な小文字aliasからfromを生成しません。一般語の聞き間違い、誤重複、噛み、false startは辞書には登録しません。

切り出し

自動選択時は正の値で音声を外側へ広げ、負の値で内側へ縮めます。字幕パネルで開始単語・終了単語を手動選択した場合は、このpaddingや最大長ではなく、画面に表示されたYouTube動画タイムコードの開始～終了をそのまま音声区間として切り出します。 保存ボタンを押すまで待っても区間は変わりません。

通常は 0 のままでOKです。現在はYouTube字幕トラック自身のタイムコードを使います。動画側の字幕時刻そのものがずれている場合だけ補正してください。

初期値は3です。「Yes.」「Oh.」など短すぎる字幕単位は候補から除外します。
